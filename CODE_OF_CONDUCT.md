# Code of Conduct

FastAction aims to be a practical, respectful, and technically rigorous open-source project.

## Expected Behavior

Participants are expected to:

- communicate respectfully and directly
- focus criticism on code, design, documentation, and behavior
- assume good intent while still asking for clear evidence
- welcome users with different experience levels
- protect private data, credentials, and customer information

## Unacceptable Behavior

Unacceptable behavior includes:

- harassment, threats, or personal attacks
- discriminatory language or conduct
- publishing private information without permission
- sharing secrets, tokens, private endpoint details, or customer data
- deliberately derailing technical discussion

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this code of conduct. Maintainers may also temporarily or permanently restrict participation.

## Reporting

Report conduct concerns privately to the maintainers through the repository owner profile. For security-sensitive issues, use the process in `SECURITY.md`.
